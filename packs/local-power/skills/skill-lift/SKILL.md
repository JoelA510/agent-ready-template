# Run the enrolled benchmark

Use the selected skill's preregistration, dataset and benchmark lock under `evals/skill-lift/`. Confirm the decision is current and the operator has provisioned scoped credentials and a provider-enforced spending cap. Use the reviewed benchmark workflow or its local command with the same inputs. If qualification or funding is missing, report the missing prerequisite and run only the credential-free rehearsal. Keep raw traces private and report both arms, incomplete attempts and costs.
